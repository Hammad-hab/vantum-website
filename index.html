What's included

JWM, no tray

A tuned JWM setup with the traditional panel and tray removed entirely, just a themed desktop and a real terminal, nothing sitting idle in the background.

Vantyl and Vantask

A GTK3 application launcher and a taskbar written from scratch for Vantum in python, built to replace the taskbar rather than imitate it. Still under active development.

Ubuntu Jammy packages

Binary compatibility with Ubuntu 22.04 LTS — install most Ubuntu software without friction, through a package manager that's been fixed to actually work.

A curated, minimal app set

Thunar, urxvt, epdfview, galculator, GParted. System necessities are just shell scripts in gtk-dialog

FAQ

Why another Puppy fork?

Most Puppy variants keep the traditional desktop shell. Vantum rebuilds the shell itself — no tray, a custom launcher, and a package manager that's actually been debugged end to end.

Is it stable?

It's a 0.01 Beta. Core system and package management are solid; the desktop shell (Vantask, Conky) still has open bugs listed in the roadmap above.

What hardware does it target?

Old, low-spec machines — the kind most modern distros have quietly stopped supporting well.

Does it save my files between boots?

Not automatically yet — that's the single biggest item left before 1.0. See the roadmap.

About

Built as a learning project

Vantum is a custom Puppy Linux build assembled using Woof-CE against Ubuntu Jammy packages. The entire build process (including every failure and fix) is documented in the repository. This is a 0.01 Beta: persistence is still being built, and a couple of desktop-shell bugs are open. Not a finished product. A thing that's being made, in the open.
